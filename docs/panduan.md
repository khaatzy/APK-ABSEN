# Panduan Penggunaan Aplikasi Absensi SMPN 9 Probolinggo

## 1. Untuk Moderator (Admin)
- Anda mengontrol jantung aplikasi. Login menggunakan email/password admin.
- Menu **Pengaturan Absensi**: Atur titik lokasi sekolah di peta, ubah radius meter toleransi, dan tentukan jam kedatangan.
- **Jangan memberikan akses moderator kepada sembarang orang**, karena role ini dapat memanipulasi data absen.

## 2. Untuk Guru Piket / Wali Kelas
- Buka aplikasi saat jam piket. Sebuah QR Code raksasa akan muncul.
- Minta anak-anak berbaris dan men-scan QR tersebut dari HP mereka sendiri. 
- Jika Anda adalah Wali Kelas, di bagian bawah ada menu ekstra untuk:
  * Menyetujui pendaftaran aplikasi Orang Tua.
  * Menyetujui Surat Izin/Sakit.
  * Mengimport 40+ siswa sekaligus memakai template Excel.

## 3. Untuk Siswa
- Login memakai: **Username = NISN (10 Digit)**, **Password = NIK (16 Digit)**.
- Aplikasi akan memblokir Anda jika Anda ketahuan memalsukan GPS (Fake GPS).

## 4. Untuk Orang Tua
- Daftar baru pakai Email dan Password. Masukkan NISN anak Anda, lalu foto KK & Kartu Pelajar sebagai bukti.
- Jika sudah disetujui Wali Kelas, layar akan berubah menjadi Peta Pelacak lokasi anak dan status kehadiran anak.
